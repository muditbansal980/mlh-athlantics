## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment

```bash
cp server/.env.example server/.env
```

### 3. Run Development Servers

- **Frontend:** `npm run dev:client`
- **Backend:** `npm run dev:server`
